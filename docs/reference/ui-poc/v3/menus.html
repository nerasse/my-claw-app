Les menus

L'app ouvre 60 feuilles, un menu ancré, quatre tiroirs et deux invites, avec quatre hauteurs de contrôle et trois largeurs qui ne se parlent pas. Deux formes ici, et une seule métrique : 34 px sur le web, 46 sur téléphone, 320 de large.

Le menu ancré

Pour une action légère sur un objet précis — le ⋯ d'un groupe, le menu d'un dossier. 236 px, ancré sous son contrôle, sans voile : il n'interrompt pas la lecture, il ne doit donc pas la recouvrir.

Un choix multiple porte une coche, pas un fond plein : le fond sert au survol, qui est un état temporaire.
