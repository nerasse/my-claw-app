Le résolveur fusionnait les limites par objet : dès qu'un modèle déclarait context, son output disparaissait au lieu d'hériter du global. Deux chemins étaient touchés, resolver.ts:245 et :265.

Ce qui change

  • La fusion se fait champ par champ, plus par objet entier.
  • Un modèle qui ne nomme pas output hérite du plafond global.
  • Le test garde son intention, pas son assertion.
